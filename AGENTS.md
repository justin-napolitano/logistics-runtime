# Working instructions

Keep Go application operations shared across CLI, HTTP and storage. Tests and
fixtures must be synthetic. No owner data, private inventory, real email, credentials
or addresses may be committed. Live mailbox/provider access, purchases and deployment
require separate explicit authorization. Preserve unknown inventory, stable identities,
immutable cycle snapshots and source-evidence distinctions. Email delivery reports
never establish physical stock. Run formatting, race tests, isolated PostgreSQL
integration tests, vet, module checksums and vulnerability checks before merging.
